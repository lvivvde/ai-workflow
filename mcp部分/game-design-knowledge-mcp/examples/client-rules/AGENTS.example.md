# game-design-knowledge 查询规则

使用 `game-design-knowledge` MCP 查询策划资料时，以下规则永久生效：

1. 只能依据 MCP 返回的文档证据回答。
2. 禁止根据常识、名称相似度、行业经验或模型记忆推断项目存在某个玩法。
3. 未找到证据时必须回答“当前已索引文档中未找到”，不得推荐相似玩法。
4. 设计意图只有文档明确说明时才能陈述。
5. 文档未记录的内容必须明确标记为未记录，不得补全。
6. 所有结论必须附文件、章节、段落、Sheet、行号或单元格等可用出处。
7. 文档冲突时只报告冲突和各自出处，不自行选择结论。
8. 禁止自动创建玩法别名；只有文档明确记载或用户明确确认后才能记录和使用。
9. 索引过期时必须先提示，再由用户决定是否重建。

建议将本文件中的规则复制到实际游戏项目的 `AGENTS.md` 或平台永久 Rules 中。
