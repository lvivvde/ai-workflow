# examples

存放当前项目内部共享的策划资料、配置与端到端示例。该目录跟随项目的访问权限管理，可以保存真实项目资料，不要求为了索引流程额外脱敏；内容不得复制到项目环境之外。

当前 AI 生成的第一批完整资料放在 `sample-corpus/`，后续可以继续替换或补充为项目实际资料：

```text
examples/
└── sample-corpus/
    ├── docx/       # AI 生成的 Word 策划文档
    ├── xlsx/       # AI 生成的配置表、数值表和文案表
    ├── csv/        # AI 生成的 CSV 配置数据
    ├── markdown/   # AI 生成的 Markdown 方案
    ├── pdf/        # AI 生成或转换的 PDF 文档
    └── pptx/       # AI 生成的演示和评审材料
```

这些文件用于项目内查询、手工验证和端到端索引测试。专门构造的边界或异常文件应放到 `tests/fixtures/`，不要混入正常资料语料。

当前示例验收只索引 `docx/` 与 `xlsx/` 中的 6 份文件；其他目录为后续格式扩展预留。
