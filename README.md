# ai-workflow

个人 AI 工作流合集：精选的 MCP 工具与 Skills 索引，含 AI 可执行的搭建指引。

## 目录结构

```
ai-workflow/
├── README.md            ← 你在这里（仓库总览）
├── AGENTS.md            ← AI 搭建执行手册（给 AI agent 读）
├── mcp部分/              ← MCP 工具索引
│   ├── code-review-graph/
│   └── simple-game-client/   （自建项目，英文）
└── skill部分/            ← Skills 合集索引
    ├── mattpocock-skills/
    └── superpowers/
```

## 给 AI agent

如果你是被派来搭建这套工作流的 AI：请阅读 [AGENTS.md](./AGENTS.md) 并按步骤执行。

## 给人

每个子目录是一份索引文档（是什么、为什么选它、官方文档链接）。项目本体均不镜像，安装请按 AGENTS.md 或各索引中的官方命令。
